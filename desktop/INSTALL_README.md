# Подготовка Windows (экспериментальная)

**Это только установщик зависимостей. Само настольное приложение и автоматический цикл ещё не готовы.** Не рассчитывайте пока на работу 24/7.

1. Скачайте ZIP ветки `feat/desktop-automation`, распакуйте. Откройте распакованную папку проекта.
2. Запустите `INSTALL.bat`. Доступ к Интернету обязателен. Установщик использует Windows winget и автоматически принимает соглашения пакетов Python 3.12, FFmpeg и Ollama, если их нет. Возможны запросы Windows на подтверждение установки.
3. Установщик создаёт отдельную среду `desktop/.venv`, ставит зависимости Python и CUDA-библиотеки, скачивает TwitchDownloaderCLI в `desktop/tools/` с проверкой SHA-256, затем загружает через Ollama `qwen3:8b` и локальную модель Whisper large-v3-turbo.
4. При ошибке прочитайте сообщение в окне и запустите `INSTALL.bat` повторно. Личный `config.json`, профили и готовые файлы не изменяются. Уже существующую папку инструмента установщик не заменяет.

Модель Qwen занимает около 5,2 ГБ; Ollama, Whisper и зависимости требуют дополнительного места. По умолчанию Ollama и Hugging Face хранят модели в профиле Windows, не в папке проекта. Нужны актуальный драйвер NVIDIA, Windows 10 22H2 или новее и App Installer (winget). Прокси, если он нужен для начальной загрузки, должен быть настроен до запуска установщика.

Установка не подтверждает качество Qwen для поиска реакций, работоспособность GPU или Twitch API. Для мониторинга потребуются Twitch client ID и client secret; интерфейс и настройка доступа ещё разрабатываются. Реальная установка и работа в Windows пока не проверены.
