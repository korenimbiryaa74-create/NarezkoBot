# Установка на Windows (экспериментальная сборка)

Полная работа на Windows, Python 3.15 и RTX 5060 ещё не проверена; не рассчитывайте на автономную работу 24/7 без проверки.

1. Скачайте ZIP репозитория из ветки `main` и распакуйте в доступную для записи папку.
2. Убедитесь, что установлен 64-битный Python 3.15. Запустите `INSTALL.bat` с Интернетом. Установщик не заменяет системный Python; создаёт `desktop/.venv`, устанавливает зависимости, FFmpeg и Ollama через winget при необходимости, скачивает TwitchDownloaderCLI, whisper.cpp и модели Whisper large-v3-turbo и Qwen3-8B. Возможны запросы Windows на установку.
3. Запустите `START.bat`. Войдите через кнопку «Войти в ChatGPT». Доступ к ChatGPT необходим и для локального теста.
4. Чтобы проверить обработку без ожидания стрима, нажмите «Открыть папку тестовых видео», скопируйте видео туда и после завершения копирования нажмите «Запустить тест из папки». Следите за очередью и ошибками. Для короткого видео можно установить минимальную длину реакции 0 минут. Результаты — в папке `recordings/Тест .../`. Файл остаётся в `test_input` до удаления пользователем.
5. Для обычного мониторинга введите Twitch Client ID и Client Secret, логины стримеров и настройки в интерфейсе, затем нажмите «Сохранить и запустить». VOD должен быть сохранён и доступен. При перезапуске возможны задания, требующие проверки и ручного повтора, особенно после неопределённой отправки в ChatGPT.

В тесте используется исходное локальное видео вместо мониторинга и скачивания Twitch; Whisper, ChatGPT, рендер и текущие параметры обработки настоящие. Отсутствие реакций может быть корректным результатом. «Продолжить очередь» запускает сохранённые задания без добавления ещё одного теста.

Qwen3-8B скачивается только для будущего сравнения и пока не участвует в поиске реакций: сопоставимое с ChatGPT качество не подтверждено. Нужны свободное место (модели занимают несколько гигабайт), актуальный драйвер NVIDIA, Windows с App Installer (winget) и доступ к загрузкам; если нужен прокси для установки, настройте его заранее.

При ошибке установки сохраните текст окна. Установщик не удаляет `config.json`, профили и результаты; папки установленных инструментов автоматически не перезаписываются. В конфигурации локально хранятся секреты — не публикуйте её и профили браузера. Обновление из нового ZIP делайте с сохранением личных данных, либо используйте Git-клон для `git pull`.
