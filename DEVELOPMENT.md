# Незавершённая разработка

Эта ветка не является готовым приложением. Здесь есть только задел: очередь заданий, компонент мониторинга Twitch и экспериментальная подготовка зависимостей Windows. Интерфейс и полный цикл обработки пока не подключены, не использовать для круглосуточной работы.

Мониторинг наблюдает эфиры, замеченные во время работы, и ожидает архив с совпадающим `stream_id`; архив должен иметь неизменную длительность в течение заданного времени. Состояние сохраняется в SQLite. Недоступность Twitch не считается завершением стрима. Без сохранённого на Twitch VOD обработка не начнётся. Гарантий, что запись полностью обработана Twitch, стабильная длительность не даёт.

Для разработки: `python -m unittest discover -s tests -v`. Эти тесты имитируют Twitch; реальная интеграция и установка на Windows не проверены.
