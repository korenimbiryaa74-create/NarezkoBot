# Тестовое видео

Положите сюда видео MP4, MKV, MOV, WEBM, M4V или AVI. Дождитесь полного копирования, затем в приложении нажмите «Запустить тест из папки». Вложенные папки не проверяются. Не изменяйте и не удаляйте файл до окончания задания. Исходник не удаляется.

Тест выполняет реальное распознавание Whisper и поиск через ChatGPT, но не проверяет мониторинг Twitch и загрузку VOD. Для короткого видео в настройках уменьшите минимальную длину реакции (например, до 0 минут). Отсутствие найденных реакций возможно и само по себе не означает ошибку. Результаты появятся в `recordings/Тест .../`, ход и ошибки — в очереди приложения. Требуются установленный Whisper, FFmpeg и действующий вход в ChatGPT.

Можно обработать несколько файлов одновременно, они будут идти по очереди. При повторном нажатии новые задания создаются для завершённых или завершившихся с ошибкой файлов; активные не дублируются. Для продолжения сохранённой очереди после перезапуска нажмите «Продолжить очередь». После неопределённой отправки в ChatGPT возможен статус ошибки, который требует проверки перед ручным повтором.


Транскрипция тестового видео сохраняется в `state/test_transcripts` и повторно используется для того же содержимого, размера и времени изменения файла и совместимых настроек распознавания. Перед использованием программа считывает видео для проверки содержимого — на больших файлах это может занять время. Старые части транскрипта при наличии истории могут переноситься из `_work/transcripts` прежних тестов: старый кэш проверяется по имени, размеру и времени изменения файла, так как контрольной суммы у него нет. Если файл подменялся с сохранением этих признаков, удалите соответствующий старый кэш до нового запуска. Изменение параметров распознавания или видео может потребовать повторной транскрипции. Поиск реакций выполняется отдельно.

Кнопка «Очистить историю» скрывает завершённые и ошибочные задания. «Очистить очередь» отменяет и скрывает ожидающие и ожидающие повтора задания, но не прерывает работающее. Мониторинг может добавить новые задания. Записи сохраняются в базе для защиты от повторной обработки и переноса старого кэша, поэтому это очистка отображения, а не удаление базы. Кэш, исходники, нарезки и настройки обе кнопки сохраняют; события на экране очистятся после перезапуска.
