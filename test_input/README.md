# Тестовое видео

Положите сюда видео MP4, MKV, MOV, WEBM, M4V или AVI. Дождитесь полного копирования, затем в приложении нажмите «Запустить тест из папки». Вложенные папки не проверяются. Не изменяйте и не удаляйте файл до окончания задания. Исходник не удаляется.

Тест выполняет реальное распознавание Whisper и поиск через ChatGPT, но не проверяет мониторинг Twitch и загрузку VOD. Для короткого видео в настройках уменьшите минимальную длину реакции (например, до 0 минут). Отсутствие найденных реакций возможно и само по себе не означает ошибку. Результаты появятся в `recordings/Тест .../`, ход и ошибки — в очереди приложения. Требуются установленный Whisper, FFmpeg и действующий вход в ChatGPT.

Можно обработать несколько файлов одновременно, они будут идти по очереди. При повторном нажатии новые задания создаются для завершённых или завершившихся с ошибкой файлов; активные не дублируются. Для продолжения сохранённой очереди после перезапуска нажмите «Продолжить очередь». После неопределённой отправки в ChatGPT возможен статус ошибки, который требует проверки перед ручным повтором.
