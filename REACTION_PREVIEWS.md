# Экспериментальные превью реакций

Генератор предназначен только для проверки: он сохраняет JPG рядом с нарезкой и **не ставит его на YouTube**. Существующая функция автоматической публикации видео работает независимо. Если сейчас ничего не нужно публиковать, отключите её во вкладке «YouTube».

## Подготовка

1. После обновления файлов запустите `INSTALL.bat`, чтобы установить новые зависимости Pillow и yt-dlp. Перезапустите программу.
2. В папке проекта создайте папку `thumbnail_assets`, а внутри неё — папку с Twitch-логином каждого стримера, например `thumbnail_assets/kussia88/`. Распакуйте туда PNG-вырезы **с прозрачным фоном**. Для другого стримера создайте отдельную папку с его логином. Файлы пользователя в `thumbnail_assets` не попадают в Git.
3. В настройках откройте «Превью реакций», включите создание и сохраните настройки. Для обработки обычного Twitch VOD используется логин записи. Для локальных тестовых видео укажите в этом разделе Twitch-логин нужного стримера.
4. Создайте нарезки заново. Для тестов разных стримеров из локальных видео обрабатывайте их по одному: перед запуском каждого сохраните соответствующий логин и дождитесь завершения. Кнопка «Тест превью» на главном экране относится к другому, уже существовавшему тесту генератора; для этого сценария она не нужна.

## Что происходит

- Вместе с таймингами и типом момента в существующем запросе к ChatGPT запрашиваются название и короткая надпись. Отдельный запрос ChatGPT ради превью не делается. Если включено удаление донатов, оно по-прежнему может использовать свой отдельный запрос.
- Превью создаётся только для моментов с типом `reaction`. Для `discussion` превью не создаётся.
- Поиск YouTube работает без ChatGPT: в поиск отправляются заголовок и до двух коротких фрагментов текста из начала транскрипта соответствующей нарезки, а не весь транскрипт. Он сравнивает текст и выбирает кандидата; при слишком слабом совпадении ничего не создаётся.
- Картинка берётся из обложки найденного YouTube-видео в максимально доступном качестве, затем компонуется с PNG-вырезом и надписью. Это не поиск Twitch VOD: дата стрима не определяется и кадры в высоком качестве с Twitch не скачиваются.
- Рядом с JPG лежит JSON с запросами, выбранным источником и другими кандидатами. **Любой результат помечен «требует проверки»**: текстовое совпадение не доказывает, что видео именно то. Проверьте ссылку, обложку, надпись и название перед использованием. Слишком длинная надпись сохраняется как есть и помечается предупреждением в журнале и JSON; автоматически её не обрезаем.
- При отсутствии выреза, надписи, подходящего источника или при сетевой ошибке превью пропускается, а готовые нарезки сохраняются. Причина появляется в журнале. Существующие JPG и JSON не перезаписываются.

Реальную работу поиска и оформление нужно проверить на ваших трёх стримах: распознавание речи, названия, доступность поиска YouTube и точность подбора источника могут различаться.
