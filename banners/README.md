# Образцы баннеров

Сюда приложение сохраняет образцы рекламных баннеров (PNG + JSON с размером кадра).
Добавляйте их в «Настройки → Обработка → Добавить образец из видео…»: найдите кадр с баннером,
выделите мышью его неподвижную непрозрачную часть и сохраните. Каждый баннер достаточно добавить один раз;
для анимированных или выезжающих баннеров добавьте 2–3 образца из разных моментов.
Удалить образец — удалите его PNG и JSON из этой папки. Файлы не коммитятся в Git.
