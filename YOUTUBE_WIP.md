# Очередь публикаций YouTube — в разработке

Это только заготовка очереди. Она **не подключена к приложению**: вход в Google, интерфейс настроек, загрузка видео и отложенная публикация на YouTube ещё не реализованы. Установка этой ветки сама по себе ничего не публикует. Не используйте её как готовую функцию.

`youtube_queue.py` планирует клипы после привязки проверенного ID канала к профилю стримера. Для обычного задания: первый клип без задержки, остальные с интервалами 1 или 16 часов от подтверждения первого. Для профиля `__test__` каждый клип без задержки. Очередь фиксирует ID канала и сведения о файле; повторная постановка идентичного задания не создаёт копий. Прерванная/неопределённая загрузка требует проверки, автоматического повтора нет. План времени здесь — только запись в SQLite, не расписание на YouTube.

Проверки: `python -m unittest discover -s tests -p test_youtube_queue.py -v`. Тесты не обращаются к YouTube. Необходимо дописать и проверить: выбор профиля и привязку реального канала после ручного входа, пользовательские настройки, интеграцию с завершением обработки, загрузку и подтверждение расписания в YouTube Studio, обработку ошибок и ручное разрешение неопределённых состояний. Не ставьте статус подтверждённой публикации без проверки принятого YouTube результата, канала и времени. Реального теста на Windows/YouTube пока нет.
